# 🗺️ NovaOS Roadmap

## Version 1.0 (Current)
- [x] Debian Bookworm base with XFCE 4.18
- [x] Orchis Dark theme + Papirus icons
- [x] Calamares graphical installer
- [x] ZRAM + service optimization (≤200 MB idle)
- [x] Flatpak + AppImage + Wine support
- [x] Plymouth boot splash + LightDM theme
- [x] Full documentation + VirtualBox testing guide

## Version 1.1 — Wayland Option
- [ ] Add Wayfire compositor as optional session
- [ ] Labwc window manager alternative
- [ ] Keep X11 as default for compatibility
- [ ] Wayland-native XFCE (when XFCE 4.20 releases)

## Version 1.2 — Android App Support
- [ ] Waydroid integration for Android apps
- [ ] GUI launcher for Android apps
- [ ] Pre-configured Waydroid images

## Version 1.3 — NovaOS Control Center
- [ ] Custom settings application (GTK4)
- [ ] One-click service manager (enable/disable Bluetooth, printers, etc.)
- [ ] Theme switcher (dark/light/custom)
- [ ] Driver manager
- [ ] Update manager GUI

## Version 1.4 — Hardware Optimization
- [ ] Custom kernel with stripped modules
- [ ] Hardware-specific profiles (laptop battery, desktop performance)
- [ ] GPU driver auto-detection and installation
- [ ] Improved power management

## Version 2.0 — Next Generation
- [ ] Custom lightweight desktop environment (GTK4-based)
- [ ] Native Wayland only
- [ ] Custom app store with curated lightweight apps
- [ ] Snap support (optional)
- [ ] Cloud sync settings
- [ ] ARM64 support (Raspberry Pi, etc.)

## Ongoing
- Security updates from Debian Stable
- Community theme contributions
- Performance regression testing
- Documentation improvements
- i386 (32-bit) builds for legacy hardware
